# Hey there! I'm Benedetta 👋

Biomedical engineer and PhD researcher at **KU Leuven**, FWO PhD Fellow in Strategic Basic Research. I work on **EEG-based auditory attention decoding**: working out from brain signals which speaker a listener is attending to, as a step towards neuro-steered hearing aids.

## About me
- 📊 Passionate about signal analysis and neuroengineering
- 🏥 Interested in technologies that can improve healthcare and medicine through AI and biomedical engineering
- 🌙 Previously worked on automated sleep disorder assessment using polysomnographic data
- 🗣️ MSc thesis at Politecnico di Torino on speech signal analysis in Parkinson's disease using deep learning
- 🎙️ Strong interest in voice and speech processing, probably because I genuinely love communication and human interaction!
